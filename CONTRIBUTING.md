# Contributing

Thanks for helping improve We Belong!

## Branching & PRs
- Branch from `main` using `feature/<desc>`, `fix/<desc>`, or `chore/<desc>`.
- Keep PRs small and linked to an Issue (`Closes #123`).

## Definition of Done (applies to every story)
- Acceptance criteria met; demoable
- Tests pass (CI green)
- Accessibility basics (focus, labels, contrast) checked
- Docs/minutes updated if applicable

## Commit style
Use conventional commits if possible: `feat:`, `fix:`, `docs:`, `chore:`, etc.
