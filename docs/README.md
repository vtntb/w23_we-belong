# Flagstaff's We Belong — Inclusive Community Platform

Helping people with intellectual disability discover welcoming clubs—and helping clubs become truly inclusive.

## Overview
We Belong connects people with intellectual disability to local hobby/interest/sports groups and equips clubs with practical inclusion tools (micro‑learning, checklists, task‑mod templates). MVP is accessibility‑first (WCAG 2.2 AA), mobile‑friendly, and delivered in agile two‑week sprints.

## Roadmap & Assessments (A1–A6)
- A1: Initial project description (problem, audience, market, management, risks)
- A2: Requirements & initial design
- A3: Interactive prototype
- A4: Design progress & working prototype snapshot
- A5: Marketing & technical videos
- A6: Final product & documentation (TechExpo)

## How we work
- Two‑week sprints on a single GitHub Project board
- Issues have owner, estimate, milestone (A1…A6), and acceptance criteria
- All changes via PRs with reviews & CI
- Fortnightly client reviews; weekly minutes & individual diaries (Moodle)

## Getting started
1. Clone this repo
2. Run `scripts/bootstrap.sh` (or `.\scripts\bootstrap.ps1`) to create labels, milestones, and branch protection (requires GitHub CLI `gh`)
3. Open the Project board and start Sprint 1
4. Use `docs/minutes/` template for every formal meeting

## Repo layout
- `.github/` – automation, issue/PR templates, workflows
- `docs/minutes` – agendas & minutes (upload to Moodle too)
- `docs/decisions` – ADRs (architecture/decision records)
- `src/` – application code
- `scripts/` – helper scripts
